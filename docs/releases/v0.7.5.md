# agy-staff 0.7.5 — Visible external-worker context

## Changes since 0.7.4

Background dispatches now print the selected AGY worker. Job lists, observations, and diagnostics retain worker identity, while delivered result text keeps its existing stable format. This makes external `agy`/`agy2`/`agy3` work visible in Codex, Claude Code, and other host transcripts without pretending that an external process is a host-native subagent.

The companion contract, worker-pool selection, legacy single-worker behavior, and Claude Code compatibility are unchanged.

## Validation

- Offline tests cover dispatch, list status, result delivery, pool worker selection, and existing lifecycle behavior.
- Pi skill generation remains validated with `npm run check:pi`.

## Upgrading

Update the marketplace and plugin in your host, then restart the host. Codex: `codex plugin marketplace upgrade agy-staff` followed by `codex plugin add agy@agy-staff`. Claude Code: `claude plugin marketplace update agy-staff` followed by `claude plugin update agy@agy-staff`.
