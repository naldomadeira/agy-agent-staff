# agy-staff 0.7.4 — Optional multi-worker pool

## Changes since 0.7.3

Adds an opt-in worker pool for installations that expose multiple Antigravity CLI executables, such as `agy`, `agy2`, and `agy3`. Existing skills keep the legacy `AGY_BIN || agy` execution path unless a caller explicitly requests a worker or the new `pool` skill.

The companion discovers workers from `AGY_BIN`, `AGY_POOL_BINS`, PATH candidates, and optional repository configuration. It records the selected worker with each job, keeps affinity for continuations and restarts, observes configurable per-worker capacity, and refuses silent migration when the original worker becomes unavailable. The `workers` command provides an inspection table.

Parallel dispatch remains limited to independent work. Concurrent writes require separate worktrees or explicit authorization. Shell aliases and functions cannot be discovered by Node; use real executables or configured paths.

## Validation

- The full offline suite passed: 210 tests.
- Pool discovery, load selection, capacity, affinity, legacy compatibility, continuation, restart, and unavailable-worker cases are covered by the new unit and integration tests.
- Generated Pi skills passed `npm run check:pi` and the diff passed whitespace validation.

## Upgrading

Update the plugin and restart Codex or Claude Code to load version `0.7.4`. A normal one-worker installation needs no configuration. See the [upgrade instructions](../REFERENCE.md#upgrading) and the optional worker-pool section in the reference.
