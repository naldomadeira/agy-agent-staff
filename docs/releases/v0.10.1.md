# v0.10.1

This release delivers the AGY pool hardening from PR #16 to Claude Code and Codex installations.

## Authentication failures and audit

A terminal AGY authentication error now ends the job as `error` with reason `auth_failed`, even
when AGY returned a partial response first. The partial response remains available and is labeled
unverified. A recovered 401 in an earlier diagnostic line does not override a different final
failure, and a recovered quota error does not hide a terminal 401.

The selected worker ID and executable path, together with start and finish times, remain in the
existing job state and `status` output. The `wait` header identifies the worker. No OAuth token or
account email is added to the audit record. Older jobs cannot be reconstructed from this change.

## Worker guidance

The staffer template asks workers to execute directly unless the task authorizes subagents and to
report completed and pending artifacts. The pool skill recommends smaller image batches with
requested, saved and reviewed counts. The jobs skill documents a named `typecheck` gate.
